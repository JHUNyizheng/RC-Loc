# 局限性与有效性威胁

1. 四个定位数据集均为公开 Wi-Fi RSS 指纹，不是新的 RFID、BLE、UWB、CSI 或蜂窝
   RSRP 现场采集；AIoT 跨模态结论仍需在目标硬件和场地上重新验证。
2. WRF-GS+ 官方论文使用 6,000 个 915 MHz RFID 样本，而公开代码库只包含固定
   160/40 的 200 样本子集。本文执行相同的 200,000 次优化预算，但不把公开子集 SSIM
   与论文 6,000 样本结果视为直接可比。
3. UJI 与 UTS 官方测试同时可能包含设备、路线和时间变化，无法从现有元数据中完全分解
   各漂移来源。因此鲁棒性归因限于受控 AP 擦除/RSS 噪声以及长期数据的总体时间偏移。
4. 五种子精确符号翻转检验的最小方向性 p 值为 1/32=0.03125。测试指纹数量很大但高度
   相关，本文不以样本级显著性夸大证据。
5. MRC-Graph 在 UJI 和 UTS 上显著改善尾部误差，但在只有 446 个训练锚点的 Tampere
   上与 PCA-WKNN 统计持平且均值略差；方法不宣称在所有小样本场景普遍占优。
6. 验证分位数缩放的半径在 Tampere 上覆盖不足，且前向时间偏移破坏严格可交换性。
   因此覆盖率只作为风险诊断，不表述为有限样本无分布保证。
7. 精确邻居图搜索成本随无线电地图规模线性增长。本文为避免额外精度/速度调参未使用
   近似邻居索引；大规模边缘部署应单独验证索引误差和时延。
8. 固定成对拓扑惩罚在完整消融中略微降低 UJI 和 UTS 性能，已从最终模型移除并作为
   负面结果保留，避免事后选择性报告。
